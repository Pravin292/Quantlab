## 4. What I would suggest (advice, not a decision)
- **NSE: Zerodha Kite Connect** is the cheapest route with 5-minute history and, from the one report found, a candle layout that matches our 71 used slots. Its largest gap is licence text on storage and aggregate publication: **ask Zerodha support in writing** (a one-line email) before acquiring. **TrueData** is the fallback if you want an explicit written licence: it already says publication needs permission, so you would obtain that permission, but pricing is by quote.
- **US: Alpaca free plan with `feed=sip`**, after a small confirmation that historical bars older than 15 minutes really are all-exchange. If its terms do not allow aggregate publication, switch to Databento.
- **Do not use Yahoo** (revised, personal use only, 60-day limit; `docs/03`).
- Because the H1 test uses returns only, a feed with trades from one exchange would still give real prices but sparse, stale-prone bars; completeness is the real risk, and `docs/33` N6 stops the run if sessions are missing.
